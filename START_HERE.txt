🚀 QUICK START (< 5 minutes):
────────────────────────────────────────────────────────────────

1. npm install

2. Copy .env.example to .env.local
   Add your Firebase credentials

3. npm run dev
   (Open http://localhost:3001)

4. Visit http://localhost:3001/admin/login
   Create an admin account

────────────────────────────────────────────────────────────────

🌍 DEPLOYMENT:
────────────────────────────────────────────────────────────────
